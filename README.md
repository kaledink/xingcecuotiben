# 行测错题本

一个在浏览器里运行的公考行测错题本。导入卷子和答案解析 PDF，自动拆成一题一页；做题时计时、可开画板演算；交卷后看各模块用时和正确率；错题和笔记可以按模块导出成 PDF，打印出来重做。

不需要注册，也没有服务器：所有数据只保存在你自己设备的浏览器里。

## 功能

- **导入试卷**：选择卷子 PDF 和答案解析 PDF，自动识别题号、模块（按卷面一级标题，如“第一部分 政治理论”“二、言语理解与表达”）和资料分析、篇章阅读的材料。
  - 扫描版 PDF 会先在浏览器里做文字识别（OCR），每页几秒，不会上传到任何地方。
  - 识别不准的地方，可以在页面上点一下题目开头手动补。
  - 答案支持“1-5 ACBBA”答案表和“1.【答案】A。解析：…”逐题解析两种写法。
- **卷型**：内置国考副省级、北京选调、上海选调、广东选调的模块构成和分值，交卷后按分值估分、对比建议用时。
- **做题**：一题一页，自动计时，可标记，可开画板（支持 Apple Pencil，手指滚动、笔写字），答题卡跳题，中途退出会保存进度。
- **练习报告**：总正确率、各模块正确率和用时、答题卡；点开任意一题看解析、写笔记、标知识点。资料分析、数量关系、图形推理的解析会从答案 PDF 截取原图，公式和图不会丢，也可以把原图加进笔记。
- **随手记与总结**：做题或看解析时，右侧随手记；所有随手记按题号汇总到这套卷子的报告下面，可以写卷子总结。
- **待办**：根据每套卷子的错题、模块正确率、用时和薄弱知识点生成待办清单。
- **错题本 / 笔记**：按模块分组，勾选后重新做（自动判分）、导出 PDF（题目在前、答案和解析在最后），笔记可导出 PDF 或 Markdown。
- **知识点自动识别**：内置“模块 › 专题 › 知识点”三层知识点树；导入后按解析开头的“本题考查……”“可判定本题为……问题”等表述自动给题目标知识点，识别不出的可以一键交给 AI 补全，也可以手动改。
- **总体报告**：跨套卷对比正确率、估分、每题用时的变化趋势，各模块能力变化（星级 + 较上次），模块 × 套卷热力表，各知识点得分率，以及自动或 AI 生成的阶段总结和建议待办。平均每题不到 15 秒的练习（多半是对答案录入）自动不计速度，也可以手动排除某次练习。
- **练习历史**：整卷练习和错题重做的所有记录，可筛选、继续未完成的、回看报告。
- **AI 功能（可选）**：填入自己的大模型 API Key（DeepSeek、通义千问、Kimi、智谱、OpenAI 或其他 OpenAI 兼容接口）后，可以用 AI 补全知识点、写单卷总结、总体报告的阶段总结和待办。不填也不影响其他功能。

## 部署成网址（免费）

这是一个纯静态网站，整个文件夹放到任何静态托管上就能用。

### 方式一：GitHub Pages

1. 在 GitHub 新建一个仓库（Public），比如叫 `cuotiben`。
2. 把这个文件夹里的**所有文件和子文件夹**上传到仓库根目录（网页上点 “Add file → Upload files”，整个拖进去）。
3. 进入仓库 **Settings → Pages**，Source 选 “Deploy from a branch”，Branch 选 `main`、目录选 `/ (root)`，保存。
4. 等一两分钟，页面上会显示网址，形如 `https://你的用户名.github.io/cuotiben/`。

### 方式二：Cloudflare Pages（国内访问通常更稳）

1. 注册并登录 Cloudflare，进入 **Workers & Pages → Create → Pages → Upload assets**。
2. 起一个项目名，把这个文件夹直接拖进去，点 Deploy。
3. 得到形如 `https://项目名.pages.dev` 的网址。

> 注意：直接双击 `index.html` 用 `file://` 打开时，扫描版文字识别等功能会失效，请通过上面的网址使用。

## 使用建议

- **iPad / iPhone**：用 Safari 打开网址后，点“分享 → 添加到主屏幕”，以后从主屏幕图标打开。这样像 App 一样全屏，数据也更不容易被系统清理（Safari 可能会清除长期未访问网站的本地数据）。
- **定期备份**：首页“数据与备份”里可以导出一个备份文件，换设备或换浏览器时用“导入备份”恢复。
- **数据不同步**：每台设备、每个浏览器的数据是分开的。

## 数据与隐私

- 试卷图片、做题记录、笔记全部保存在浏览器的 IndexedDB 里，不会上传。
- PDF 解析和文字识别都在本地完成。
- 只有在你主动开启 AI 功能时，相关题目文字、解析、笔记才会发送给你选择的 AI 服务商；API Key 只保存在当前浏览器的 localStorage 里。
